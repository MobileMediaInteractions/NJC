# Engineering investigations

Investigations are evidence packages, not production dependencies. Each folder
must state its hypothesis, method, results, limitations and decision. A result
does not authorize a migration by itself.

- [Bun and Protocol Buffers](bun-protobuf/README.md) evaluates the claimed
  latency and payload benefits against this repository's actual workloads.
