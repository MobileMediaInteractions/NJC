# NJC+ versioned assets

Components reference this set only through `src/lib/njc-plus-assets.ts`, so a
future approved identity can replace a version or move the manifest to another
version without rewriting product pages.

`v1/signal-field.png` was produced with OpenAI image generation from an original
abstract brief: an obsidian broadcast field with chartreuse, cyan and coral
signal geometry, no words, logos, people, network marks or copied layouts.

The SVG wordmarks and icon are original project-native assets. Dark and light
variants retain the same signal mark and use no third-party network branding.
