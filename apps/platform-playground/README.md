# Platform Animation Playground

This Next.js workbench exercises the production animation language, compiler,
FlatBuffers package and browser runtime independently of Studio. It is a
developer surface for deterministic compilation, playback, reverse playback,
responsive viewport inputs and reduced-motion behavior.

![Animation Playground in dark mode](../../docs/screenshots/dark/platform-playground.jpg)

```bash
pnpm --dir apps/platform-playground dev
pnpm --dir apps/platform-playground typecheck
pnpm --dir apps/platform-playground lint
pnpm --dir apps/platform-playground build
```
