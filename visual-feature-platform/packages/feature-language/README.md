# `@visual-feature/language`

This package parses and formats the controlled-English feature language,
projects typed models into readable source, reports source ranges and powers
language-service operations used by Studio.

![Readable feature source in the dark-mode playground](../../../docs/screenshots/dark/platform-playground.jpg)

The full authoring reference is
[the language and Blueprints guide](../../docs/language/authoring-language-and-blueprints.md).
