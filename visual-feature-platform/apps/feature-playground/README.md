# Visual Feature Playground

This Vite application is the standalone host for compiled visual-feature
packages. It proves purchase and live-information examples without depending
on the desktop Studio shell and exposes simulation, runtime trace and package
verification states.

![Visual Feature Playground in dark mode](../../../docs/screenshots/dark/visual-feature-playground.jpg)

```bash
pnpm --dir visual-feature-platform/apps/feature-playground dev
pnpm --dir visual-feature-platform/apps/feature-playground typecheck
pnpm --dir visual-feature-platform/apps/feature-playground build
```
